---
title: Omarchy Widget
description: See your upcoming events in the Omarchy bar
---

The [Caldir widget for Omarchy](https://github.com/t4t5/omarchy-caldir-widget) gives you quick access to upcoming calendar events from the Omarchy bar. It works with renCal's calendar data, highlights your next meeting, and lets you join video calls or open events in renCal with one click.

Install it as an Omarchy plugin:

```sh
omarchy plugin add https://github.com/t4t5/omarchy-caldir-widget --enable
```

See the [widget's documentation](https://github.com/t4t5/omarchy-caldir-widget) for keyboard shortcuts, settings, and customization options.
